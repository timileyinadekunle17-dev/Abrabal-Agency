# Abrabal Agency

Responsive single-page agency website built with semantic HTML, custom CSS and lightweight JavaScript.

## Preview locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save. GitHub will publish the site at the Pages URL shown in that settings panel.

The supplied design reference remains in `references/website-design-reference.jpeg`.
